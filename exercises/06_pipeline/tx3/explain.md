# Explain It — tx3

Draw (or describe in words) a decision tree for choosing between Pipeline, Transaction, and Lua script.

Write it in `feynman/explanations/tx3.md`.

Your decision tree must answer:
1. Do I need the result of command A to decide what command B does?
2. Do I need all commands to succeed together (or none)?
3. Do I need results of commands during execution (not just after Exec)?
4. Is latency more important than atomicity?

Include at least one real example for each branch of the tree.

QUALITY CHECK: Could a developer use your decision tree in a code review to justify their choice?
