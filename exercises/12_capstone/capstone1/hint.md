This is the capstone. You have all the knowledge. The bugs are described in the exercise comments in `main.go`.

Read the test file carefully — the tests tell you exactly what must pass and why.

**Estimated time: 45-60 minutes**

- Module 09 lua1 (compare-and-swap) for ARGV indexing
- The `XPending` call in `GetPendingCount` — what does an empty PEL mean?
